# TrustVis — BMVC 2026 Workshop Website

Static, responsive one-page website for **TrustVis: Workshop on Trustworthy Visual AI for Online and Public Safety**.

## Important dates

- Submission deadline: **12 September 2026, 23:59 AoE (UTC−12)**
- Author notification: **26 September 2026 (AoE)**
- Participation confirmation: **3 October 2026 (AoE)**
- Camera-ready deadline: **16 October 2026 (AoE)**
- Final program published: **23 October 2026 (AoE)**
- Workshop: **26 November 2026 (Lancaster local time, GMT)**

Submission site: [TrustVis on OpenReview](https://openreview.net/group?id=bmva.org/BMVC/2026/Workshop/TrustVis#tab-your-consoles)

Submission format: use the [official BMVC 2026 template](https://bmvc2026.bmva.org/authors/author-guidelines/); papers may be up to **14 pages, excluding references**.

## Files

- `index.html` — all page content and links
- `styles.css` — responsive layout and visual design
- `script.js` — mobile navigation, active-section state and footer year
- `assets/logo.svg` — workshop logo
- `assets/trustvis-hero-v1.webp` — conceptual hero visual generated for the workshop page
- `assets/trustvis-social-preview.webp` — social-preview crop; connect it to `og:image` after the public site URL is known
- `assets/bmvc-2026.png` — local derivative of the official BMVC 2026 mark
- `assets/institutions/` — official-source institution marks and provenance notes
- `assets/people/` — local organiser and prospective-speaker portraits with source notes

## Before publishing

Add any remaining author instructions once the review criteria and archival policy are confirmed. The submission deadline is verified against OpenReview; later workflow dates still require organiser confirmation. Speaker information can also be updated when invitations are confirmed.

## GitHub Pages deployment

1. Create a GitHub repository, e.g. `trustvis-bmvc2026`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`.
